# Coze Knowledge 企业人才培养知识库素材包

本目录用于上传到 Coze Knowledge，目标是支持智能体根据岗位需求自动生成人才培养方案。

## 文件说明

- `01_岗位能力表.md`：36条岗位能力数据，覆盖AI、数据分析、产品经理、运营、市场营销、人力资源。
- `02_课程映射表.md`：企业培训风格课程与能力映射数据。
- `03_培养目标模板.md`：10套培养目标模板，覆盖AI、数据分析、产品、运营、市场、HR、管培生和中层管理者。
- `04_岗位课程映射数据.md`：25组岗位、能力、课程映射数据。
- `05_Coze知识库优化建议.md`：说明哪些内容放知识库、哪些放Prompt，以及格式选择建议。

## 上传建议

建议直接上传本目录中的 Markdown 文件。Markdown 标题和表格结构更利于 Coze Knowledge 识别字段、段落和语义关系。

## 使用边界

本素材包不包含 SQL、数据库、API、前后端代码、LangChain 或 Multi-Agent 内容，只作为知识库材料使用。
