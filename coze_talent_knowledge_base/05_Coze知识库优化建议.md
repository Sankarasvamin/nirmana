# Coze Knowledge 知识库优化建议

## 适合放入 Coze Knowledge 的内容

- 岗位能力表：用于检索岗位职责、核心能力、技能关键词和能力等级。
- 课程映射表：用于根据能力名称匹配企业培训课程、学习目标和适合阶段。
- 培养目标模板：用于生成不同岗位或人才类型的培养目标、核心素养、能力要求和成长路径。
- 岗位-课程映射数据：用于让智能体在回答时快速关联岗位、能力和课程。
- 企业内部制度类材料：如岗位序列、职级标准、胜任力模型、培训目录、认证规则、导师制规则。

## 适合放入 Prompt 的内容

- 输出格式要求：例如必须输出“培养目标、能力差距、课程安排、阶段计划、评估方式”。
- 角色设定：例如“你是企业人才发展顾问，面向HR和业务负责人生成培养方案”。
- 生成规则：例如“不编造不存在的岗位课程，优先使用知识库中的课程名称”。
- 约束条件：例如“不输出数据库、API、后端代码，不生成高校理论课程”。
- 交互流程：例如先询问岗位、行业、员工当前能力、培养周期，再生成方案。

## 提高检索命中率的方法

- 使用统一字段名：岗位、能力、课程、学习目标、难度等级、适合阶段等字段不要频繁变化。
- 为同一概念补充关键词：例如“数据分析、经营分析、BI、指标体系、可视化”可以同时出现。
- 每条知识保持独立完整：一行或一个小节应包含岗位、能力、课程、阶段等关键信息，避免只写缩写。
- 避免过长段落：长文档建议按岗位、能力、课程拆分成多个短小条目。
- 使用明确标题：Markdown 中使用“## 岗位名称”“### 能力要求”等标题，方便语义检索。
- 保留企业培训语言：使用“岗位胜任、骨干提升、管理岗、项目交付、业务复盘”等表达。
- 控制同义词混乱：例如固定使用“岗位”而不是在不同文件中混用“职位、角色、职务”。
- 上传后做测试问题：用“为数据分析师生成3个月培养方案”“AI产品经理需要哪些课程”等问题验证命中。

## Markdown、CSV、XLSX 的选择建议

Markdown 更适合本知识库当前上传场景。岗位能力表、课程映射表和岗位-课程映射数据都可以用 Markdown Table 表达，字段清晰，同时保留标题层级，便于 Coze Knowledge 进行语义切分和检索。

CSV 适合企业内部做结构化维护，例如用表格工具批量增删岗位、课程和能力字段。但如果直接上传到 Coze Knowledge，建议先转换为 Markdown。

XLSX 适合企业内部多人维护和人工筛选，但上传到知识库前建议转换为 Markdown，减少格式解析不稳定的问题。

本素材包推荐组合：
- 岗位能力表：Markdown
- 课程映射表：Markdown
- 培养目标模板：Markdown
- 岗位-课程映射数据：Markdown
- 知识库使用规则与优化建议：Markdown

## 建议的 Coze Prompt 约束

你可以在智能体 Prompt 中加入以下规则：

```text
当用户提出岗位培养方案需求时，优先从知识库检索岗位能力表、课程映射表和培养目标模板。
输出内容必须包含：岗位理解、核心能力、能力差距、推荐课程、阶段计划、评估方式。
课程名称应优先使用知识库中的企业培训课程，不生成高校课程风格的内容。
如果知识库中没有完全匹配岗位，应根据相近行业、相近能力和技能关键词进行组合，并说明依据。
不要输出SQL、数据库、API、后端代码、前端代码、LangChain或Multi-Agent方案。
```
